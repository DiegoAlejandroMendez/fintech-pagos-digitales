#  PayColombia - Plataforma FinTech para pagos digitales

##  Descripción
Este proyecto consiste en el diseño y desarrollo de un prototipo de plataforma FinTech orientada a facilitar pagos digitales en Colombia, especialmente en pequeños comercios.

El sistema permite simular funcionalidades como:
- Registro de usuarios
- Gestión de billetera digital
- Generación de códigos QR
- Simulación de pagos
- Historial de transacciones

##  Metodología
Se utilizó la metodología ágil Scrum para el desarrollo del proyecto, organizando el trabajo en sprints.

##  Prototipo
El prototipo fue desarrollado en Figma mediante un diseño interactivo que simula el funcionamiento del sistema.

Link del prototipo:
https://depict-stock-84009089.figma.site/

##  Nivel TRL
El proyecto alcanza un nivel de madurez tecnológica TRL5, validado en un entorno simulado.
